# WaveFox 
------------------------------------
## О проекте

WaveFox - аудиоплеер и менеджер локальной музыки для Windows. Создавайте свою библиотеку музыки - создавайте плейлисты, сортируйте треки, настраивайте очередь прослушивания.

------------------------------------

## Тип проекта

Тип проекта: десктопное приложение (аудиоплеер) для Windows.

------------------------------------

## Цели и задачи

- [x] Разработать удобный десктопный аудиоплеер для ОС Windows с современным и интуитивно понятным интерфейсом.
- [x] Реализовать воспроизведение аудиофайлов различных популярных форматов, управление воспроизведением, громкостью и порядком треков.
- [x] Реализовать музыкальную библиотеку с автоматическим сканированием файлов, отображением исполнителей, альбомов, треков и обложек.
- [x] Добавить поддержку плейлистов, поиска, сортировки и фильтрации музыкальной коллекции.
- [x] Реализовать хранение настроек пользователя, библиотеки и истории прослушивания.
- [x] Разработать дополнительные функции, такие как эквалайзер, горячие клавиши и скробблинг прослушанной музыки.

------------------------------------
