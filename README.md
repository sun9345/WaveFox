# WaveFox 
## О проекте

WaveFox - аудиоплеер и менеджер локальной музыки для Windows. Создавайте свою библиотеку музыки - создавайте плейлисты, сортируйте треки, настраивайте очередь прослушивания.

------------------------------------

## Тип проекта

десктопное приложение (аудиоплеер) для Windows.

------------------------------------

## Цели и задачи

- [ ] Разработать удобный десктопный аудиоплеер для ОС Windows с современным и интуитивно понятным интерфейсом.
- [ ] Реализовать воспроизведение аудиофайлов различных популярных форматов, управление воспроизведением, громкостью и порядком треков.
- [ ] Реализовать музыкальную библиотеку с автоматическим сканированием файлов, отображением исполнителей, альбомов, треков и обложек.
- [ ] Добавить поддержку плейлистов, поиска, сортировки и фильтрации музыкальной коллекции.
- [ ] Реализовать хранение настроек пользователя, библиотеки и истории прослушивания.
- [ ] Разработать дополнительные функции, такие как эквалайзер, горячие клавиши и скробблинг прослушанной музыки.

------------------------------------
